For parents This game exercises sorting waste into recycling, compost and general rubbish. Every few pickups, the snake asks which bin the last item belongs in. A wrong answer explains why in one line, so the reasoning sticks rather than just the rule. Only items that sort the same way in most countries are used. Questions can be switched off with the tickbox above.
