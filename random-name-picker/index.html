    What Is a Random Name Picker?

    A random name picker selects one or more entries from a list you provide. Use this random name selector to make a fair choice without writing slips of paper. It picks from your names; it does not generate new names.

    How to Pick a Random Name

    1. Enter or paste your names, one per line.
    2. Choose how many names to pick, or leave it at one.
    3. Click Pick a Name to reveal your selection.

    Enable Remove picked names to work through the list without reusing an entry. Reset List restores all entries. Editing the text starts a fresh list.

    Ways to Use a Random Name Picker

    Choose a classroom student to answer a question, pick winners for a giveaway, decide who goes first in a game, or assign turns in group activities. To choose teams, pick a batch for one team, remove those entries, and repeat for the next team.

    Random Name Picker FAQ

    How does the Random Name Picker work?

    Your browser uses cryptographic random numbers with unbiased sampling to select entries. Each line has an equal chance. The brief name cycle is visual feedback and does not affect the result.

    Can I paste a list of names?

    Yes. Paste one name per line. Spaces at the beginning and end are trimmed, and blank lines are ignored. Duplicate names remain separate entries, so a name listed twice has two chances.

    Can I pick multiple names?

    Choose 1, 2, 3, or 5 entries. Options larger than the available list are disabled. Each entry can appear only once within a batch, but separate entries with the same name may both be selected.

    Can I prevent the same name from being picked twice?

    Turn on Remove picked names. Each selected entry is removed from subsequent draws. If a name appears on multiple lines, its other entries remain eligible; use one line per person to prevent this. Reset List restores the full list.

    Can I use it as a random winner picker?

    Yes. Enter the eligible names and pick one or more winners. Give each person one entry for equal chances per person.

    Are the names I enter stored?

    No. The tool keeps your list only in the current page's memory. It does not save names locally or remotely, or include names in analytics. Reloading the page clears the list.
