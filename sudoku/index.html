Sudoku

Nine numbers. One satisfying solution.

How to play Sudoku

Fill each empty cell with a number from 1 to 9. Each row, column, and outlined 3×3 box must contain every number exactly once. The darker starting numbers are fixed. You do not need arithmetic—look for where each number can fit.

  1. Select an empty cell. Its row, column, and box are highlighted.
  2. Tap a number on the number pad, drag it onto an editable cell, or type 1–9. The chosen number stays highlighted on the pad. Use the arrow keys to move between cells.
  3. Turn on Notes to record possible numbers. Tap a number again to remove that note. Turn Notes off to enter an answer.

Wrong answers are underlined in red and count as mistakes. Drag an entered answer outside the board to erase it, or use Erase. There is no mistake limit: erase or replace a wrong number and keep going. A correct placement removes matching pencil notes from its row, column, and box.

Choose your challenge

There are 120 bundled puzzles: 30 each in Easy, Medium, Hard, and Expert. Every puzzle has been automatically checked to have exactly one solution. Choose a difficulty in Next puzzle, then press New puzzle; changing the menu alone does not replace your current board.

Easy puzzles can be solved with cells that have only one possible answer. Medium puzzles also need you to find a number's only possible location in a row, column, or box. Hard adds candidate-elimination techniques such as pairs and locked candidates. Expert needs techniques beyond that set. Difficulty is approximate and depends on your experience.

Hints, timer, and saved games

Hint reveals the correct answer in the selected editable cell. If that cell is already correct or is a starting clue, it finds another cell to help with. Hints are counted separately from mistakes.

The timer measures time while this tab is visible and stops on completion. Progress, pencil notes, time, and hint/mistake counts save automatically in this browser when storage is available. Come back to continue your latest puzzle. Clearing browser data removes that saved game; private browsing may prevent saving.

Where should I start?

Look at rows, columns, or boxes with many numbers already filled. For an empty cell, rule out every number already in those three groups. If only one remains, you can place it. If several remain, record them as notes and inspect another area.

Does Sudoku need an account or internet connection to get new puzzles?

No account is needed. The puzzle collection loads with the page, so New puzzle does not call an external puzzle service. The website still needs to load initially; it is not an installed offline app.

Can the same puzzle appear twice?

New puzzle randomly chooses a puzzle from the selected difficulty and avoids the last one you played at that level. Earlier puzzles can reappear after you have played another.
